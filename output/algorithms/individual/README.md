Add `00-preamble.tex` to your document preamble once. Paste any algorithm file inside your document body. Do not paste a second document class or document environment. Algorithm numbers are assigned automatically in document order.

The snippets contain algorithm panels only; the original source and PDF retain the interpretation notes and source-function references. Number-dependent mentions of other algorithms have been replaced with their names, so snippets can be reordered.

LaTeX compilation has not been tested in this environment.
